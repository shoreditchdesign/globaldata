# Project conventions

## File naming

- HTML files: sentence case (`Sprint 2 wrap-up.html`, not `Sprint 2 Wrap-Up.html` or `sprint-2-wrap-up.html`).
- Markdown files: all caps with hyphens (`SPRINT-2-DECK-OUTLINE.md`, not `Sprint-2-Deck-Outline.md`).
- Code files: kebab-case (`table-cell.ts`), except React component files, which keep PascalCase to match their exported component name (`Button.tsx`, `HeaderCell.tsx`) per the existing `packages/ui/src` convention.
